# 🎯 Number Guessing Game  

A simple yet fun **Python-based Number Guessing Game** where the player tries to guess a secret number between 1 and 100. With limited attempts, best score tracking, replay option, and the ability to quit anytime, this project is perfect for beginners to practice Python basics in a fun way.  

---

## ✨ Features  
- 🔢 Random number generation (1–100)  
- ⏳ Limited attempts (7 chances per game)  
- 🚪 Exit anytime by typing `exit`  
- 🏆 Tracks your **best score** (lowest attempts)  
- 🔁 Replay option to play multiple rounds  
- ⚠️ Handles invalid inputs gracefully  

---

## 🛠️ Technologies Used  
- **Python 3** (core language)  

---

## ▶️ How to Run  

1. Make sure you have **Python 3** installed.  
2. Download or copy the file `guessing_game.py`.  
3. Open a terminal/command prompt in the project folder.  
4. Run the game with:  
   ```bash
   python guessing_game.py
